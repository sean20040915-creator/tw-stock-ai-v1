免費台股 AI 多空分析系統 v3 → v4
====================================

你不需要重建 Streamlit 網站，也不用換網址。

步驟 1
下載並解壓縮 tw_stock_ai_v4.zip

步驟 2
打開你原本的 GitHub repository：tw-stock-ai-v1（或你實際使用的 repository）

步驟 3
把下面 3 個檔案上傳並覆蓋原檔：

1. streamlit_app.py
2. stock_engine.py
3. requirements.txt

README.md 可一起更新，但不影響網站執行。

步驟 4
GitHub 按 Commit changes。

步驟 5
回到原本的 Streamlit 網址。
Streamlit Community Cloud 通常會依 GitHub 新版本重新部署。
若仍顯示舊版，可重新整理網頁。

成功後網站標題應顯示：
「免費台股 AI 多空分析系統 v4」

建議測試：
1. 查 2330。
2. V/A 歷史統計 → 看期望報酬 / 盈虧比。
3. 每日訊號中心 → 先掃 5–10 檔。
4. 測試近1日新V、近3日新V、近5日新V。
5. 測試快速升溫、連續轉強。
6. 查看最近 V 品質 A/B/C/D 與品質分數。
7. 下載 v4 每日訊號 CSV。

注意：
A/B/C/D 是研究用訊號品質分級，不是買進建議。
歷史勝率、期望報酬與盈虧比均不保證未來結果。
