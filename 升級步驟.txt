免費台股 AI 多空分析系統 v2 → v3
==================================

你不用重建 Streamlit 網站，也不用換網址。

1. 下載並解壓縮 v3。
2. 打開你原本的 GitHub repository。
3. 把下面 3 個檔案上傳並覆蓋：
   - streamlit_app.py
   - stock_engine.py
   - requirements.txt
4. 按 Commit changes。
5. 回到原本的 Streamlit 網站，等待重新部署。
6. 網站標題應變成：免費台股 AI 多空分析系統 v3

建議先測試：
A. 2330 個股分析
B. V/A 歷史統計
C. 每日訊號 / 自選股 → 預設清單 → 掃描最新訊號
D. 下載自選股 CSV
E. 匯入剛下載的 CSV

如果 GitHub 更新後畫面沒變：
- 到 Streamlit 的 Manage app / App settings 執行 Reboot。

注意：
- 自選股使用免費的 Session State，不是永久資料庫。
- 建議把自選股 CSV 存在自己的電腦/手機，需要時重新匯入。
- 每次最多掃 25 檔，避免免費 API 額度過快耗盡。
