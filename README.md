# 免費台股 AI 多空分析系統 v5

v5 在 v4 的「四色力道、V/A、每日訊號中心、V 品質、期望報酬、walk-forward」基礎上，新增 **V 訊號策略研究實驗室**。

## v5 新功能

你可以針對目前查詢的個股，自行設定：

- V 品質：A / B / C / D，可複選
- 最低力道
- 最低量比
- 是否加入最低 20 日動能門檻
- 最長持有 5 / 10 / 20 個交易日
- 是否啟用停損、停損幅度
- 是否啟用停利、停利幅度
- 沿用側欄的單邊交易成本假設

按下「執行策略回測」後會顯示：

- 實際交易次數
- 勝率
- 每筆期望淨報酬
- 平均獲利 / 平均虧損
- 盈虧比
- Profit Factor
- 累積報酬
- 最大回撤
- 平均持有交易日
- 每日資金曲線
- 每筆交易紀錄
- 相同條件下持有 5 / 10 / 20 日的快速比較
- CSV 下載

## 回測如何避免常見的偷看未來

1. V 訊號是在當天收盤後才確認，因此 **一律下一交易日開盤進場**，不使用 V 當天收盤價假裝成交。
2. V 品質、力道、量比、20 日動能等篩選條件，只使用訊號當時已知資料。
3. V 品質中的歷史表現，只使用該次 V 以前、而且結果已經完成的舊 V 樣本。
4. 最近尚未走滿使用者設定持有期的訊號，不會硬塞進已完成績效。
5. 同一時間只允許一筆全資金部位，持倉期間的新 V 不重複開倉。

## 停損 / 停利模擬規則

- 停損、停利以進場價為固定基準。
- 若開盤已跳空越過停損或停利價，使用實際開盤價出場。
- 若某一天的日 K 高低價同時觸及停損與停利，因為日資料無法知道盤中先後順序，v5 採 **較保守的停損先發生**。
- 沒有碰到停損 / 停利，就在持有期最後一天收盤出場。
- 交易成本在進場、出場各扣一次。

## 最大回撤

v5 的策略實驗室不是只看每筆交易結束後的資產，而會建立每日 mark-to-market 資金曲線；持倉期間使用每日收盤估值，實際出場日使用模擬出場價格，因此最大回撤比單純用逐筆已實現報酬更有參考性。

## 升級方式

不用建立新的 Streamlit App，也不用換網址。

把下列檔案覆蓋到原本 GitHub repository：

1. `streamlit_app.py`
2. `stock_engine.py`
3. `requirements.txt`

然後 Commit changes，原本的 Streamlit Community Cloud App 會使用新的 GitHub 版本重新部署。

## 建議第一次測試

1. 股票輸入 `2330`。
2. 歷史期間先選 5 年；如果 A/B 級樣本太少，可改 8 年。
3. 打開「策略研究實驗室」。
4. 先測預設：A/B 級、力道 >= 55、量比 >= 1、持有 10 日、停損 6%、停利 12%。
5. 若完全沒有交易，可以加入 C 級、降低量比，或把歷史資料改成 5/8 年。
6. 比較持有 5 / 10 / 20 日結果，不要只挑最好看的單一參數。

## 重要限制

這是教育與研究工具，不是投資建議，也不是保證獲利的交易系統。歷史回測容易受到樣本數、參數挑選、交易成本、滑價、資料品質、市場制度變化等因素影響。

目前策略實驗室尚未完整模擬：

- 個別券商實際手續費折扣
- 台股不同商品的完整稅費差異
- 滑價
- 漲跌停無法成交
- 流動性不足
- 股利 / 除權息
- 公司行動的所有細節
- 部位大小與多檔投資組合

因此請把結果當作「歷史規則檢驗」，不要把回測績效直接等同未來績效。
