# 免費台股 AI 多空分析系統 v9

v9 主題：**參數穩健性研究（Parameter Robustness）**。

本版沿用 v8 的投資組合模擬器與 v6/v7 的前向驗證，不修改 AI 模型與 V/A 訊號演算法。目的不是找出一組歷史績效最高的「神參數」，而是檢查一組策略在相鄰參數下是否仍有一致結果，降低過度最佳化（overfitting / curve fitting）的風險。

## 新增功能

- 新增「參數穩健性」頁籤
- 一次掃描多組：
  - 最低力道
  - 最低量比
  - 持有日數
  - 停損%
  - 停利%
- 最多 120 組參數（免費主機保護限制）
- 每組仍使用 v8 相同的多檔投資組合資金限制、交易成本與下一日開盤進場規則
- 顯示：交易數、累積報酬、年化報酬、最大回撤、Sharpe、勝率、期望報酬、盈虧比、Profit Factor
- 「鄰近參數」一致性：查看相鄰力道／量比／持有日／停損／停利是否也維持正期望與正報酬
- 穩健區標記：用於辨識較寬的參數平台
- 孤立高峰警示：歷史結果突出、但鄰近設定不支持時標記
- 力道 × 量比熱圖
- 單一參數敏感度表
- 全部掃描結果可下載 CSV

## 重要觀念

v9 的「穩健分數」不是股票評分、不是未來報酬預測，也不會自動替你選出應該採用的策略。它只是研究工具，用來找出歷史結果是否集中在一個較寬的平台，而不是只出現在單一參數點。

建議判讀順序：

1. 先看交易樣本數是否足夠。
2. 再看大部分參數組合是否為正期望／正報酬。
3. 看熱圖是否形成一片相近區域，而不是只有一格特別漂亮。
4. 看最大回撤是否隨小幅參數變化就劇烈惡化。
5. 最後仍要用 v6 起累積的前向驗證紀錄檢查真實 out-of-sample 表現。

## 建議第一次測試

股票池先用 4～6 檔，例如：

`2330, 2317, 2454, 2308, 2382, 2303`

歷史期間建議 5 年或 8 年。

參數先用：

- V 品質：A/B/C（若 A/B 樣本太少）
- 最低力道：55, 60, 65
- 最低量比：0.8, 1.0, 1.2
- 持有日：5, 10, 20
- 停損：4%, 6%
- 停利：8%, 12%

這會產生 108 組，仍在 120 組上限內。

## 研究限制

歷史穩健不等於未來有效。資料來源、交易成本、滑價、公司事件、除權息與市場結構改變都可能讓結果失效。不要只因某個參數區域歷史表現較佳，就把它視為投資建議。
