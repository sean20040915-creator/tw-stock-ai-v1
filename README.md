# 免費台股 AI 多空分析系統 v4

v4 延續 v3 的零付費方向，把「每日訊號 / 自選股」升級成更完整的每日訊號中心。這一版的重點不是增加更多神祕指標，而是讓 V/A 訊號更容易用歷史資料檢驗。

## v4 新增功能

- 近 1 / 3 / 5 個交易日新 V 篩選
- 近 1 / 3 / 5 個交易日新 A 欄位
- 力道 3 日 / 5 日變化
- 連續轉強日數
- 「快速升溫」條件
- 最近 V 品質分數（0–100）與 A / B / C / D 研究分級
- V/A 期望方向報酬
- 平均獲利 / 平均虧損
- 盈虧比
- Profit Factor
- 近 5 日新 V 的品質與歷史經濟性專區
- 精簡版 / 完整版每日訊號表
- CSV 匯出仍保留完整研究欄位

v3 的功能全部保留，包括：

- 四色力道 K
- V/A 訊號
- V/A 5 / 10 / 20 日歷史勝率
- Random Forest 未來 5 日上漲機率
- Expanding-window walk-forward
- 交易成本假設與回測
- 自選股匯入 / 匯出
- 免費觀察池選股排行
- FinMind + Yahoo Finance 備援

## 近 1 / 3 / 5 日新 V 怎麼算？

以「交易日」而不是日曆天計算：

- 近 1 日新 V：最近一次 V 就在最新資料列（距今 0 個交易日）
- 近 3 日新 V：最近一次 V 距今 0–2 個交易日
- 近 5 日新 V：最近一次 V 距今 0–4 個交易日

因此週末不會被誤算成兩天。

## 連續轉強與快速升溫

- **連續轉強日數**：力道分數連續上升的交易日步數。
- **快速升溫**：力道 3 個交易日增加至少 10 分，或 5 個交易日增加至少 15 分。

這些規則只使用當下與過去資料。

## V 品質分數

V 品質是本專案自行設計的可解釋研究分數，並不是買進評等。

總分 100：

- 最多 70 分：V 訊號當下已知的技術條件
  - 力道分數
  - MA20 / MA60 趨勢排列
  - 股價相對 MA20
  - MACD Histogram
  - RSI
  - 成交量比
  - 20 日區間位置
  - V 當下之前的力道斜率
- 最多 30 分：**在這次 V 發生以前就已經完成結果**的歷史 V 樣本
  - 樣本數
  - 5 日方向勝率
  - 5 日期望方向報酬

重要：這次 V 之後才發生的股價不會進入這次 V 的品質分數，因此不會用結果反過來替訊號加分。

研究分級：

- A：80–100
- B：68–79.99
- C：55–67.99
- D：低於 55

分級只用來整理研究訊號，不代表適合買進或未來一定上漲。

## 為什麼加入期望報酬與盈虧比？

只看勝率容易誤導。例如一個訊號可能勝率很高，但成功時只小幅獲利，失敗時卻出現較大損失。

v4 對 V / A 的 5、10、20 日結果增加：

- **期望方向報酬**：所有歷史訊號的平均方向報酬。V 之後上漲為正；A 之後下跌為正。
- **平均獲利**：歷史成功訊號的平均方向報酬。
- **平均虧損**：歷史失敗訊號的平均方向報酬（負值）。
- **盈虧比**：平均獲利 ÷ 平均虧損絕對值。
- **Profit Factor**：所有正方向報酬總和 ÷ 所有負方向報酬絕對值總和。

這些都是歷史事後統計，不代表未來維持同樣結果。

## 每日訊號中心建議用法

1. 匯入或輸入你的自選股，最多 25 檔。
2. 按「掃描 v4 訊號中心」。
3. 先看「近 1 日新 V」或「近 3 日新 V」。
4. 再看力道 3 日變化、連續轉強與快速升溫。
5. 對最近 V，同時查看 V 品質分數、歷史樣本、勝率、期望報酬與盈虧比。
6. 點選股票載入個股頁，再看 K 線、V/A 歷史紀錄與 walk-forward。

這是一套研究流程，不是自動交易或投資建議。

## 免費方案限制

- 每次自選股 / 觀察池掃描最多 25 檔。
- 自選股仍使用 Streamlit Session State；請用 CSV 匯出備份。
- 不做盤中即時逐筆資料。
- 不做自動下單。
- API 是否能取得資料仍取決於 FinMind / Yahoo Finance 當時服務狀態與免費額度。

## 建議測試順序

1. 查詢 `2330`，確認個股頁正常。
2. 打開「V/A 歷史統計」，確認新增「期望報酬 / 盈虧比」表格。
3. 打開「每日訊號中心」。
4. 用 5–10 檔自選股按「掃描 v4 訊號中心」。
5. 測試「近1日新V / 近3日新V / 近5日新V / 快速升溫 / 連續轉強」。
6. 切換「訊號中心精簡版 / 完整研究欄位」。
7. 下載每日訊號 CSV。
