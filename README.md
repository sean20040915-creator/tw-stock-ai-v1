# 免費台股 AI 多空分析系統 v3

v3 延續 v2 的零付費方向，新增「每天實際會用到」的自選股與訊號管理功能。

## v3 新增功能

- 我的自選股：最多 25 檔
- 自選股 CSV / TXT 匯入
- 自選股 CSV 匯出備份
- 每日訊號總表
- 最新資料日新 V / 新 A 篩選
- 強多 / 強空快速篩選
- 自選股技術排名、20 日動能、量比、RSI
- 每檔股票歷史 V 後 5 日勝率 / A 後 5 日勝率
- 個股 V/A 歷史統計：5 / 10 / 20 個交易日
- 最近 V/A 訊號紀錄與結果
- 從每日訊號表快速切換到個股分析

## 自選股為什麼要匯出備份？

本版使用 Streamlit Session State 儲存目前瀏覽器工作階段的自選股。這不需要資料庫，也不需要花錢，但它不是永久儲存：重新整理頁面、工作階段中斷或服務重啟時可能重置。

因此 v3 提供：

1. `下載自選股 CSV`
2. 下次使用時 `匯入自選股 CSV / TXT`

這樣仍可維持零付費，也不需要建立資料庫帳號。

## V/A 勝率怎麼算？

訊號產生規則與 v2 相同，不使用未來資料。

事後統計時：

- V 訊號：N 個交易日後股價高於訊號當日，視為方向成功。
- A 訊號：N 個交易日後股價低於訊號當日，視為方向成功。

v3 顯示 5、10、20 日統計，並顯示樣本數。未走完指定交易日的最近訊號會標記「尚未完成」。

這些是歷史統計，不代表未來會維持同樣勝率。

## 每日訊號總表

自選股掃描只跑技術指標與 V/A 歷史統計，不會對 25 檔逐一跑完整 Random Forest walk-forward，避免免費 Streamlit 主機運算過重。

表格會顯示：

- 資料日
- 收盤價 / 日漲跌
- 多空力道與四色狀態
- 最新資料日是否剛出現 V / A
- 上一次 V / A 與距今交易日數
- 20 日動能、RSI、量比
- V 後 5 日勝率 / 樣本數
- A 後 5 日勝率 / 樣本數
- 技術排名分數

「今天」在網站中實際代表「該股票最新可取得的交易日」。不同資料來源若更新時間不同，應以表格的 `資料日` 為準。

## API 額度

為了維持免費方案，自選股與選股掃描仍限制每次最多 25 檔。FinMind 官方目前說明：無 token 約 300 requests/hour；登入並使用 token 約 600 requests/hour。

網站仍有 Yahoo Finance / yfinance 備援。

## 建議測試順序

1. 個股 2330 能正常分析。
2. 開啟「V/A 歷史統計」，確認有 5 / 10 / 20 日表格。
3. 開啟「每日訊號 / 自選股」。
4. 保留預設 10 檔，按「掃描最新訊號」。
5. 測試「剛出現 V」、「剛出現 A」篩選。
6. 下載 `my_tw_stock_watchlist.csv`。
7. 再用匯入功能把 CSV 載回。

## 重要限制

- 自選股目前不是永久雲端保存。
- 不做自動下單。
- 不保證即時盤中資料。
- V/A 勝率是歷史事後統計。
- AI 機率、技術分數與排行都不是投資建議。
- 歷史回測不代表未來績效。

入口檔：`streamlit_app.py`

建議 Python：3.12
